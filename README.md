# 🍔 ASV Restaurante - Sistema de Pedidos Fast-Food

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![Google Apps Script](https://img.shields.io/badge/Google%20Apps%20Script-4285F4?logo=googlecloud)
![License](https://img.shields.io/badge/license-MIT-green)
![Status](https://img.shields.io/badge/status-ativo-success)

Sistema completo de pedidos para restaurante fast-food com duas interfaces: **Cliente** (para fazer pedidos) e **Restaurante** (painel de atendimento com acesso restrito).

---

## 📸 Demonstração

### Página Inicial
A página inicial oferece duas opções de acesso:

| Interface | Descrição |
|-----------|-----------|
| 📱 **Cliente** | Faça pedidos online e acompanhe o status em tempo real |
| 👨‍🍳 **Restaurante** | Painel de atendimento com acesso restrito por senha |

---

## 🚀 Funcionalidades

### 👤 Interface do Cliente

| Funcionalidade | Descrição |
|----------------|-----------|
| ✅ Cardápio organizado | Produtos divididos por categorias (Lanches, Bebidas, Acompanhamentos, Sobremesas) |
| ✅ Carrinho de compras | Adicione, remova e ajuste quantidades dos produtos |
| ✅ Finalização de pedido | Informe nome e telefone para identificar o pedido |
| ✅ Acompanhamento em tempo real | Visualize o status do pedido (Recebido → Preparando → Pronto → Entregue) |
| ✅ Notificações visuais | Alertas para cada atualização do pedido |
| ✅ Design responsivo | Funciona perfeitamente em celulares, tablets e desktops |

### 👨‍🍳 Interface do Restaurante

| Funcionalidade | Descrição |
|----------------|-----------|
| ✅ Fila de pedidos | Visualize todos os pedidos em cards organizados |
| ✅ Atualização de status | Mude o status: Recebido → Preparando → Pronto → Entregue |
| ✅ Estatísticas em tempo real | Contagem de pedidos por status |
| ✅ Som de notificação | Alerta sonoro quando um novo pedido chega |
| ✅ Filtros | Filtrar pedidos por status específico |
| ✅ Acesso protegido | Senha `142597` para acesso ao painel |
| ✅ Design responsivo | Interface otimizada para uso no balcão/cozinha |
